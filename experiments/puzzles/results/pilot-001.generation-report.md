# Puzzle generation

Bounded generation finished.

200 source games selected; 600 candidate positions processed; 16 verified puzzles.

Only completed checkmate games were replayed. Forced opening plies are excluded. Each accepted puzzle has an exhaustive legal-defense mate tree with one mating move per solver turn within the stated bound. Slower wins outside that bound are not ruled out. Work-limited proofs are rejected as unproven.

Piece involvement includes stationary units whose removal changes the legal mate tree; this is a conservative tactical-effect tag, not a complete motif explanation. Search priors remain the source priors. No balance game or source file was changed.

Import puzzles.json through the game's Puzzles menu. This pilot creates mate puzzles only; it does not assign a human difficulty rating.
