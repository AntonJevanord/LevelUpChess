The idea of the project is to create a chess game where the players can level their pieces up before a game and then start a
ranked or casual match with their setup. there will be 3 levels, where the pieces start at level 0 (normal) and then they can
get leveled up to lv 1(blue), lv 2(orange) or lv 3(purple). there is a max total levels depending on the game mode. the project 
uses fairy stockfish as an engine and for early balancing.
